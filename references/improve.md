# Improve

Read this when they said improve, enhance, or make it better.
One named improvement in place. "Better" is not a product.

1. If they didn't name what is better (faster, clearer, safer,
   smaller), one question. Don't guess a platform.
2. Change the named thing. No sibling feature, no new surface,
   no extra file.
3. Verify with the user path or an assertion. Quote it.

Don't: "while I'm here", a redesign. Faster is
[optimize.md](optimize.md). Cleaner shape is
[refactor.md](refactor.md).
