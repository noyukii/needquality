# Detect (confirm AI looks)

Read from [uniqueness.md](../uniqueness.md) when a fetched page
or your own landing *might* be the AI cluster. Skip for
operate/settings and for a brief that pinned that look. Core
rules in `SKILL.md` still apply.

Suspect is not confirmed. Confirm, then decide. Do not *copy* a
confirmed-AI page as the world. Do not treat a confirmed-AI
device as forbidden if the job or brief needs it (a FAQ on a
help site; a reading column on docs).

## Suspect

The page matches a [ui.md](../ui.md) fingerprint *cluster*, or
the first viewport is the doc-column on a persuade job, or
copy is streamline/empower plus a pill over the H1.

## Confirm (first that works)

1. **Already scored.** Search
   `site:slopcop.adriankrebs.ch {host}` or the
   [gallery](https://slopcop.adriankrebs.ch/show). Krebs tiers:
   0 None · 1–2 Low · 3–4 Medium · 5+ High
   ([14 patterns](https://slopcop.adriankrebs.ch/patterns)).
2. **Live score.** Open
   [slopcop.adriankrebs.ch](https://slopcop.adriankrebs.ch/),
   paste the URL, and read the tier. If the host exposes an explicitly
   requested detector, use its documented interface. Do not assume a local
   provider path or install a detector for this check.
3. **No tool.** Count fingerprint hits yourself. 5+ on a
   *new* surface = High. Quote the hits. Do not invent a
   Slopcop score you did not read.

Impeccable 2026 specimen (cream + italic Inter/Fraunces + 01/02
+ icon tiles + grid + marquee) is the *new* cluster, not only
purple glass.

## Decide

| Result | Persuade inspo | Own landing |
|---|---|---|
| None / Low | Keep. Steal the named device | Ship if the job still holds |
| Medium / High, axis free | Drop as the world. Next URL | Rework the flagged cluster |
| Medium / High, brief or read/docs earned it | Steal only the earned device, not the whole page | Keep the earned device; strip the rest |

A detector that cannot run is not a pass. Fingerprint-count, say
you did not get a live score, and still drop a free-axis High.
