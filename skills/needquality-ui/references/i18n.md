# Internationalization

Read this when they said i18n, internationalize, add translations, or
localize. Use the repo's existing library and named surface.

1. Find the locale, namespace, fallback, plural, date, and number
   conventions already in the tree.
2. Extract only the named strings into keys. Preserve interpolation,
   escaping, and the source voice. Use the library's plural and
   formatter APIs; do not concatenate translated fragments.
3. Check a longer translation, missing key, and RTL layout when those
   locales are in scope. Report locales not checked.

Don't: add a new i18n package, invent translations for an unrequested
surface, or hardcode English around a translated value.
